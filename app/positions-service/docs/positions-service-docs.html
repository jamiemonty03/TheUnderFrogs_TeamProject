Positions

Position management operations

Create or update a position

Creates a new position or updates an existing one using insert-or-update logic

Request Body schema: application/json
required
accountId
required
string

The unique identifier of the account holding the position

symbol
required
string

The trading symbol/ticker of the security

quantity
required
number <decimal>

The number of shares/units held

averageCost
required
number <decimal>

The average purchase price per share/unit (FIFO calculated)

version
integer

Version number for optimistic locking

createdAt
string <date-time>

Timestamp when the position was created

lastUpdated
string <date-time>

Timestamp of the last update to this position

updatedBy
string

User or system that performed the last update

Responses

Production Server

https://positions-service.example.com/positions

Local Development Server

http://localhost:8084/positions
