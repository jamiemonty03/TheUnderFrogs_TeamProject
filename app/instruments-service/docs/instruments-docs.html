Delete an instrument

Deletes an instrument by symbol. Note: instruments-service's ETL (db/etl/01-generate_raw_instruments.py) is the authoritative writer for the base instrument set and upserts on every run - deleting a symbol that's part of the ETL's fixed ticker list will not persist past the next ETL run.

path Parameters
symbol
required
string
Example: AAPL

The instrument's ticker symbol

Responses

Production Server

https://instruments-service.example.com/instruments/{symbol}

Local Development Server

http://localhost:8082/api/instruments/instruments/{symbol}
